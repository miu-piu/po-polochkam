Как пользоваться

1. Выберите формат. Три небольшие наклейки на одном листе или одну большую — вертикальную либо горизонтальную.

2. Добавьте надпись. Найдите готовое название в разделе «Готовые» или создайте своё. Нажмите на нужную наклейку в макете, чтобы изменить текст, уточнение или значок.

3. Подготовьте листы. Добавляйте названия одно за другим: когда все места заняты, приложение создаёт следующий лист автоматически. При необходимости лист можно добавить вручную. Все заполненные листы сохраняются в одном PDF.

Большая партия. Например, 50 небольших наклеек займут 17 листов (по три на каждом, кроме последнего). Для быстрого создания откройте «Добавить списком / JSON»: обычный список содержит по одному названию в строке, а JSON позволяет смешивать все три формата, выбирать значки и добавлять изображения. Во вкладке «Для ChatGPT» можно сгенерировать промпт, получить JSON от ИИ и вставить его сюда. Скачайте общий PDF и импортируйте его в Label Expert. Перед большой партией проверьте печать двух страниц: возможность отправить весь многостраничный PDF на печать одним заданием зависит от Label Expert.

4. Распечатайте. В разделе «Печать» скачайте PDF или PNG, откройте файл в Label Expert и выберите размер 75 × 120 мм без изменения масштаба.

Автосохранение. Черновики хранятся в браузере на этом устройстве. Регистрация не нужна, синхронизации между устройствами нет.

iPhone и iPad. Чтобы установить приложение, откройте его в Safari и выберите «Поделиться» → «На экран Домой». Для передачи PDF другому приложению удобно использовать кнопку «Поделиться PDF».

Добавить много наклеек

JSON может содержать разные форматы в одном списке. Для каждой наклейки нужны title и format; необязательно: detail, icon, image.

Значки задаются в поле icon, например "icon": "food" (еда). Допустимые значки: auto, none, box, kitchen, food, clothes, shoe, toy, plug, clean, heart, document, paw, star, tools, book, gift, suitcase.

Своя картинка: "image": "photo.png" и прикреплённый файл либо data:image/png;base64,... прямо в JSON. Картинка заменяет значок; ссылки на сайты не поддерживаются.

Выберите сценарий. Для описи вещей сначала спроектируйте места хранения. Если подписи уже определены, можно сразу запросить JSON. Приложение не обращается к ChatGPT самостоятельно.

Для описи вещей, мебели или фотографий: сначала спланируйте размещение, согласуйте подписи и лишь затем получите JSON.

Если перечень вещей находится в документе или таблице, приложите файл к сообщению в ChatGPT вместе с промптом. Здесь достаточно написать, что следует использовать этот файл.

Только реально существующие файлы PNG/JPEG/WebP. Укажите имена по одному в строке и затем приложите эти картинки к импорту JSON. Необязательное поле.
