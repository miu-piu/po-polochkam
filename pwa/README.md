# По полочкам — PWA, версия 7.1 · Batch + ChatGPT prompts

Простая офлайн-утилита для подготовки домашних наклеек под Label Expert (AIYIN IP-802BT). Работает в браузере на Android, iPhone/iPad, Windows и macOS. Само приложение не управляет принтером: оно экспортирует PDF или PNG, который затем открывается в Label Expert.

## Макеты

**Одна физическая заготовка: 75 × 120 мм** (PDF в точных миллиметрах, PNG 600×960 пикселей, около 203 dpi).

- **3 на листе:** три независимые области 75 × 40 мм, подписи редактируются по отдельности. После печати разрезать.
- **1 вертикальная:** одна надпись на весь лист.
- **1 горизонтальная:** содержимое повернуто на 90° внутри того же физического листа 75 × 120 мм. Не менять размер рулона/бумаги в принтере.

## Возможности

- 310 офлайн-названий с поиском, синонимами, категориями.
- Свои названия, необязательная подпись, выбор монохромных векторных пиктограмм.
- Нажатие по любой из трёх областей — выбор её для изменения. Отдельно «+» у каталожного названия добавляет в первое свободное место, при заполнении создаёт новый лист.
- Несколько названий с галочками — объединить в одну наклейку.
- Новые листы, переход, удаление, перестановка, дублирование наклейки, перемещение вверх и вниз.
- Разные виды листов в одной очереди, общий PDF со всеми заполненными листами; PNG выбранного листа.
- Избранное и недавние названия.
- Локальное сохранение в localStorage, миграция прежней очереди PWA v2 при первом запуске.
- Service Worker и manifest для установки PWA и офлайн-работы после первого открытия.

## Адаптивный интерфейс и доступность (v5)

- **Телефон, ширина до 760 CSS px:** вместо длинной страницы — три доступных раздела в нижней навигации: «Готовые», «Макет», «Печать». По выбору наклейки каталог закрывается, пользователь возвращается к редактированию листа. Кнопка PDF есть прямо в редакторе.
- **Планшет и десктоп:** двухпанельный list/detail: каталог слева, редактор справа; список подготовленных листов находится под макетом. Прямая кнопка PDF доступна без прокрутки до очереди.
- **Доступность:** общие размеры управления 48 CSS px, контрастные подсказки, масштабирование до 200% без горизонтального переполнения проверенных экранов, 16px ввод в Safari, фокус внутри модальных диалогов и возврат к вызвавшей кнопке после закрытия. При удалении наклейки/листа появляется действие «Отменить» на 8 секунд. Общая очистка дополнительно запрашивает подтверждение.
- `index.html` содержит адаптивную навигацию и быстрые действия. Общие стили находятся в `styles.css`. Бизнес-логика PDF/PNG и сохранения листов в `app.js` не менялась.

## Запуск

Хостить содержимое папки `pwa` по HTTPS, например через workflow GitHub Pages `.github/workflows/pwa-pages.yml`, после включения GitHub Pages с источником **GitHub Actions**. Откройте сайт один раз онлайн, затем он будет работать офлайн.

- Android (Chrome): меню → «Установить приложение» / «Добавить на главный экран».
- iPhone (Safari): «Поделиться» → «На экран Домой».
- Mac/Windows (Chrome или Edge): «Установить» в адресной строке или меню.

Файлы `index.html`, `app.js`, `ui.js`, `styles.css`, `catalog.js`, `sw.js`, `manifest.webmanifest` и `icons/` должны оставаться вместе в одной папке.

## Печать

Экспортировать PDF, передать в Label Expert и выбрать 75 × 120 мм, масштаб 100%, без обрезки. В случае проблем с PDF можно экспортировать PNG отдельного листа. Проверить тестовую печать перед партией: успешность прямого импорта в конкретную версию Label Expert и фактический масштаб на AIYIN IP-802BT пока не проверены на физическом устройстве.

## Проверки

Браузерные сценарии проверены в Chromium (Playwright): 3 независимых слота, редактирование выбранной области, поиск, создание и объединение названий, режимы 1 вертикальная/горизонтальная, смешанный PDF, иконки, избранное, история, восстановление сохранённых данных, экран 320/360/390/768/1024/1440 px. Сгенерированные PDF проверены на физический размер страниц 75×120 мм и визуально отрендерены.

## Граница проекта

Без авторизации, облака, сканирования/учёта содержимого коробок, Bluetooth-команд и сторонних JS-библиотек.


Версия 5.0: Adaptive UI на основе UI Kit v1. Единая палитра из восьми цветов, системный шрифт, единые размеры контролов и отступов, однотипные кнопки, Lucide-style SVG-иконки интерфейса. Полный набор токенов и компонентов: `UI-KIT.md`.

## Массовое добавление — v6

В разделе «Готовые» выберите **«Добавить списком / JSON»**.

- **Списком:** одна строка = одна наклейка; выберите общий формат (3 на листе, 1 вертикальная или 1 горизонтальная).
- **JSON:** вставьте текст или загрузите `.json`; можно смешивать форматы и добавлять значки или изображения.
- **Изображения:** `"image": "photo.png"` — вместе с JSON загрузите файл картинки; или `"image": "data:image/png;base64,..."` для полностью автономного JSON. Поддерживаются PNG, JPEG, WebP. Внешние HTTP(S) ссылки намеренно не поддерживаются.
- **Проверка перед сохранением:** показывается число наклеек, листов и первые позиции. Любая ошибка прерывает операцию; сохранённые листы не изменяются.
- Фотографии автоматически уменьшаются для хранения в браузере и выводятся монохромно для термопечати. Для каждой отдельной наклейки можно вручную добавить или удалить картинку в редакторе.
- Всего не более 120 листов; для больших серий делите макеты на несколько документов/PDF.
- Один многостраничный PDF имеет физические страницы 75 × 120 мм в том же порядке, что и исходный JSON.

### Формат JSON

```json
{
  "version": 1,
  "labels": [
    { "title": "Макароны", "format": "triple", "icon": "food" },
    { "title": "Крупы", "format": "triple", "detail": "На каждый день" },
    { "title": "Зимняя одежда", "format": "portrait", "image": "photo.png" },
    { "title": "Зарядки", "format": "landscape", "icon": "plug" }
  ]
}
```

Обязателен `title`; формат `format`: `triple`, `portrait`, `landscape`. `detail`, `icon`, `image`, `category` необязательны. По умолчанию формат `triple`; можно задать `defaultFormat` у корневого объекта. Также принимается непосредственно массив наклеек, а строковые элементы массива считаются названиями в формате по умолчанию. Для картинок через имена файлов выберите JSON и PNG/JPEG/WebP в диалоге выбора файлов. Для избежания потери данных не держите большие коллекции картинок только в единственном браузере: выгрузите готовый PDF.

**Импорт в Label Expert:** PWA создаёт многостраничный PDF, однако возможность печати всех страниц за один проход зависит от версии Label Expert. Перед серией сделайте тест с двумя страницами.

## Генерация промпта и импорт из ChatGPT

Во вкладке «Для ChatGPT» можно описать вещи свободным текстом, настроить форматы и иконки, сгенерировать запрос, скопировать его и открыть ChatGPT. Приложение не отправляет запросы и файлы в ChatGPT автоматически. Если список находится во вложении (документ, таблица или изображение), его нужно приложить к беседе отдельно; промпт запрещает выдумывать содержимое отсутствующих файлов.

Вкладка JSON принимает объект `{"version":1,"labels":[...]}`, где допустимы коды `triple`, `portrait`, `landscape` и 18 встроенных значков. Неподдерживаемые версии JSON отклоняются; черновик не изменяется, если импорт завершился ошибкой.
