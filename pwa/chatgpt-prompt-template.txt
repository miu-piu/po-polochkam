ШАБЛОН ДЛЯ CHATGPT — «ПО ПОЛОЧКАМ»

Задача: подготовь ТОЛЬКО валидный JSON для импорта в PWA «По полочкам» (этикетки 75 × 120 мм).

ЧТО НУЖНО ПОДПИСАТЬ:
[ЗДЕСЬ ВСТАВЬТЕ СПИСОК ВЕЩЕЙ И ПОЖЕЛАНИЯ К КОЛИЧЕСТВУ И ФОРМАТАМ]

СТРОГАЯ СХЕМА:
{
  "version": 1,
  "labels": [
    {"title": "Макароны", "format": "triple", "icon": "food"},
    {"title": "Зимняя одежда", "format": "portrait", "icon": "clothes", "detail": "Для хранения"},
    {"title": "Кабели", "format": "landscape", "icon": "plug"}
  ]
}

Правила:
1. Ответ только JSON. Без Markdown, пояснений или комментариев.
2. Создай записи по моей задаче, а не копируй пример. Каждая запись — отдельная наклейка для уже определённого места. Если передана опись вещей без схемы хранения, не создавай автоматически одну наклейку на товар: уточни места хранения.
3. У каждой записи обязательны title (1–160 символов), format и icon. detail — необязательная подпись до 100 символов.
4. format только triple / portrait / landscape; тройные соседние записи группируются по три на лист. Одна portrait или landscape занимает весь лист 75 × 120 мм.
5. Подбери форматы по назначению либо используй мои явно заданные пожелания. Не добавляй непрошенные предметы и дубликаты. Максимум 360 наклеек.
6. icon только из следующего списка:
   auto (автоматически), none (без значка), box (коробка), kitchen (кухня), food (еда), clothes (одежда), shoe (обувь), toy (игрушки), plug (техника и провода), clean (уборка), heart (уход), document (документы), paw (животные), star (хобби), tools (инструменты), book (книги), gift (подарки), suitcase (поездки).
7. Если у меня есть конкретный существующий файл PNG/JPEG/WebP для наклейки, разрешено указать необязательное поле "image": "точное_имя_файла.png". Я загружу файл вместе с JSON. Внешние ссылки, SVG и выдуманные Base64 не допускаются. image имеет приоритет над icon.
8. Не используй поля для CSS, размеров наклеек или произвольных иконок.
9. Сохраняй названия на русском, короткими и удобными для чтения. Проверь, что результат — валидный JSON.

10. Если мой запрос ссылается на прикреплённый документ, таблицу, изображение или файл — сначала проверь вложение. Извлекай перечень вещей только из реально доступного содержимого. Если вложения нет или оно нечитаемо, не выдумывай список: попроси файл, вместо того чтобы выдавать фиктивный JSON.
